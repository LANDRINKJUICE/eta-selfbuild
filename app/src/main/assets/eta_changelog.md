# Eta 自编改造版 · 变更记录

> 这是本机自签改造版的改动清单。官方 3.4.0 的原始功能不在本清单内。
> 构建方：本机 Gradle（自签 keystore）。官方界面与本版在 UI 上仅有本页与版本标识的差别。

## 3.4.0+eta5（2026-11-02）

- **定时任务**：设置页新增「定时任务」，可以设「每天几点自动做一件事」——设备状态、记忆状态、权限体检三种动作（全部本地执行、不联网、不消耗模型额度）。重启手机、改时间、覆盖安装后会自动重建闹钟；到点执行完发通知，结果直接写在通知里
- **记忆容量放宽**：记忆文件上限 1 MiB → 8 MiB；单次写入 3500 → 16000 字符；单次读取 32000 → 64000 字符
- **每轮注入的记忆更多**：核心记忆注入预算 32000 → 64000 字符，标题目录 8000 → 16000 字符
- **构建方式变化**：从「手机本地编译」改为「GitHub 云端编译 + 回手机签名」，手机不再长时间发热；云端同时跑全量单测（含本机跑不了的 Robolectric 测试）

## 3.4.0+eta4（2026-11-02）

- 记忆系统可用性：标题索引支持三级标题、索引容量翻倍；记忆页新增"核心记忆是否生效"状态（文件里没有 `# 核心记忆` 段时，每轮实际不会注入任何记忆）
- 工具能力页补上 save_screenshot（此前只能由 Agent 调用，界面里看不到）
- 提速：子代理返回内容超出上限时自动截断并附完整结果落盘路径，避免长报告拖慢主会话

## 3.4.0+eta3（2026-11-02）

- 新增本页与设置页的版本标识：装的是哪一版、是不是自签版，一眼可见
- 文件检索提速：批量扫描替代逐文件多次调用 shell，大仓库里明显更快

## 3.4.0+eta2（2026-11-02）

- 文件检索单轮预算 5 秒 → 15 秒（此前只能扫 1~3 个文件就超时）
- 后台任务等待 60 秒 → 300 秒（能一次等到十分钟级的构建）
- 单条命令上限 180 秒 → 600 秒
- 一次可读 4 张图片（此前 1 张）
- Android 与 Linux 双环境路径自动换算，不再需要人工换算
- 修复：修改文件时误报「不是 UTF-8 文本」的问题（安卓解码器在多字节字符分块边界上的行为差异）

## 3.4.0+eta1（2026-11-02）

- 新增 save_screenshot 工具：把当前屏幕截图存为文件，默认进入系统相册 Pictures/Eta，支持自定义路径与文件名
